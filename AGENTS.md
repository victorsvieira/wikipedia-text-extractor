# Wikipedia Text Extractor

Extensão Chrome Manifest V3, sem build e sem backend.
- Instalar: `npm install`
- Validar: `npm run check`
- Carregar: `chrome://extensions` → Modo do desenvolvedor → Carregar sem compactação
- Mantenha permissões e content scripts restritos à Wikipédia.
- Mudanças na extração devem atualizar testes em `test/`.
